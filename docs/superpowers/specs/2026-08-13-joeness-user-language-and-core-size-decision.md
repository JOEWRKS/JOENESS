# JOENESS 사용자 설명과 Core 크기 결정

## 결정

- 사용자에게 보내는 경과, 설명, 의견, 질문은 비전공자가 이해할 수 있는 쉬운 말을 기본으로 한다.
- 꼭 필요한 전문용어는 처음 쓸 때 바로 설명하고, 내부 작업 용어와 어색한 직역은 일상적인 말로 바꾼다.
- 에이전트끼리의 내부 대화는 제외한다. 사용자 본인이 기술 수준이나 형식을 직접 요청한 경우에만 그 요청을 우선한다.
- 활성 JOENESS Core의 최대 크기를 2,048바이트에서 3,072바이트로 바꾼다.
- 사용자 목표, 안전 또는 필요한 검증에 기여하지 않으면서 단계·승인·문서·도구 사용만 늘리는 규칙과 절차는 작업 효율을 해치는 악습으로 본다. 안전·정확성·필수 검증을 줄이는 것은 효율화로 보지 않는다.

## 이유와 범위

2,048바이트 제한은 Codex의 기술적 제한이 아니라 Core가 불필요하게 커지는 것을 막기 위한 프로젝트 기준이었다. 이 제한 때문에 안전 규칙을 모호하게 줄이거나 사용자에게 다시 설명해야 할 축약어를 만들면 목적에 어긋난다. 3,072바이트는 현재 안전 규칙과 명확한 사용자 설명 규칙을 함께 담는 상한이며, 이를 넘는 새 기능은 Core에 계속 추가하지 않고 별도 스킬로 분리한다.

이 결정은 이전 설계 문서의 2,048바이트 상한만 대체한다. 이전 Core 후보와 설계 문서는 변경하지 않고 역사 기록으로 보존한다. Core v7의 실제 사용자 응답 품질은 별도 검증 전까지 `candidate/unvalidated`로 유지한다.
