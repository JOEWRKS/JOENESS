## 3단계 — 격리 행동 검증

- [x] 관련 없는 기존 계획이 있는 프로젝트의 연결 제안.
- [x] 승인된 재규격화로 완료·미완·우회·시각 승인 경계 보존.

평가자에게 기존 기대 답·의심 결함을 주입하지 않는다. 실프로젝트에는 적용하지 않는다.
