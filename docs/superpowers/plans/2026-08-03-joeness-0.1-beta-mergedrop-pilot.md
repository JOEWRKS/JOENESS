**Goal:** Test whether JOENESS-0.1 can turn a rough MergeDrop request into coherent, verified work across implementation and a fresh-session handoff without changing the original project.

## Global Constraints

- This is a JOENESS-0.1 beta pilot, not a Native-versus-JOENESS A/B test.
- Do not modify `D:\JOEWRKS\MergeDrop` or the JOENESS source while a phase is running.
- Do not publish, deploy, purchase, alter accounts, submit store forms, or claim launch readiness without direct evidence.
- Do not rerun an incomplete or poor phase solely to obtain a better result.
- Treat timeout, false completion, unsupported claims, wrong-direction work, duplicate work, and no-progress loops as observed failures.
- Judge each category separately: request interpretation, scope, implementation quality, verification, maintainability, collaboration continuity, truthfulness, time, commands, and available token evidence.
- Extra cost is acceptable only when it produces a proportionate, separately identified quality gain.
