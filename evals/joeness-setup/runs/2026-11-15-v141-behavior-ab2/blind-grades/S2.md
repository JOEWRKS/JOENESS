전체 관찰:
- 8개 run 모두 규칙은 기존 Rule Coverage 표 한 곳에만 있고 Result 열을 더한 run은 없으며, CO3 Check는 모두 C3 행을 가리킨다(루브릭 전원 만점, 천장 효과).
- 차이는 판정 쪽에서 난다: r02는 focus를 측정하지 못해 CO3를 pending으로 두었고, r15는 C2 행의 spot check가 비어 있다는 이유로 CO2를 다시 열었다. r07은 CO1·CO2 Check를 사용자 결정으로 남겼다.
- code와 rendered 결과를 구분하는 정밀도는 run마다 다르다(r12·r16은 토큰 검사에 상태 범위를 붙임, r04는 spot check의 check 값을 50으로 씀).
