> Approval scope: a user request approves only what it names. A request to mark an item done, close it or move on does not approve a decision still pending inside it (a visible change nobody approved, an option or format you chose, an unmet closure condition). Before recording completion, ask about that decision, or keep the item open and say what is pending. Never record a decision as the user's unless the user stated it.
