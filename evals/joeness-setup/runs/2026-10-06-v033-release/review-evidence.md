# JOENESS 0.3.3 출시 기록

상태: 출시 준비. 정확한 커밋의 원격 Windows 검사·개인 설치·GEO 인계 확인 전.

## 승인 범위

사용자: “계획대로 진행 후 보고 해”. 0.3.3 버전·안내 → 로컬 배포 검사 → 커밋·푸시 → 해당 커밋 Windows CI → 설치·GEO 적용 확인. 새 A/B, GEO 기획 재작성, 다른 프로젝트 일괄 갱신은 제외한다. 현재 개발 브랜치 codex/document-normalization을 푸시하며 main 병합은 이 실행에 포함하지 않는다.

## 출시 내용과 한계

- 표준 다섯 문서·단계별 ROADMAP, 주제 Library, 정보 원본/승인 경계, 여섯 항목 요약 우선.
- 기존 문서 재편·요약 우선의 [행동 근거와 실패 이력](../2026-10-06-document-normalization/review-evidence.md) 보존.
- 상세·조회 축약 시험안은 기각. 시험 전 스킬 9파일을 그대로 출시하며 추가 규칙·길이 제한·재검수 루틴 없음.
- GEO 새 채팅은 gpt-6-astra/high. xhigh·장기 운영·일반 정확도·토큰 절감 미입증. 상세 장황함과 AGENTS 역할 설명 일부 누락은 알려진 한계.
- 전역 판단 Core 없음. 개인 설치는 소유 스킬/상태만 갱신하고 전역 AGENTS·다른 스킬은 보존. GEO는 후보 연결과 출시본 대조 후 필요한 차이만 반영.
