## 별도 비용·사용성 근거

- [설정 제안 1쌍](../2026-09-29-token-cost-ab/review-evidence.md)은 Bare 69,589, JOENESS 79,741 총 토큰으로 JOENESS +14.59%였다. 두 답변 모두 필요한 문서 역할을 찾았다. 이는 **초기 설정 한 사례의 추가 비용**이지 일상 작업마다 같은 비용이 든다는 뜻이 아니다.
- [판단 Core만의 8쌍 비교](../../../experiments/joeness-astra-independent-judgment-ab-results-2026-09-26.json)는 Bare와 Core가 모두 8/8, Core 고유 개선 0이었다. Core 입력은 합계 +1.13%였고, 시간·출력 차이는 실질 회귀로 판정하지 않았다. 사람의 목표 유용성 평가는 없다. 이 비교는 파일 작업·장기 기록·프로젝트 연결을 다루지 않았다.
- 사용자는 여섯 항목의 첫 요약을 읽기 쉽다고 평가했지만, [상세 문구를 줄인 새 채팅](../2026-09-29-mergedrop-feedback-ab/auto-handoff-recheck.md)의 개선은 크지 않아 **강한 추가 규제를 정당화하지 못한다**고 했다. 이는 여섯 항목 자체의 거부나 전체 사용성 승인으로 해석하지 않는다.
- [긴 AGENTS 안전 검사](../2026-09-29-instruction-window/review-evidence.md)는 프로젝트 연결이 기존 지침 일부를 초기 읽기 범위 밖으로 밀 수 있음을 발견했다. 도구는 해당 상태를 `blocked`로 막도록 고쳤지만, 실제 DungeonGameV3의 사용자 소유 지침 재구성 또는 연결 해제는 미결이다.

## 권고와 미결 결정

1. **프로젝트 연결: 선택형 시험으로 유지, 범위 동결.** 기존 문서 위치 연결·승인된 사실 기록은 제품 목표와 맞고 한 실제 작업에서 중대한 손상은 없었다. 그러나 Bare도 동등한 사실 복원을 했으므로 고유 성능·토큰 절감은 주장하지 않는다. 여섯 항목과 기록 규칙을 더 강제하거나 문서를 일괄 생성하지 않는다. 사람 사용성·계속 쓸 의향이 나오기 전에는 정식 출시 가치 판정을 닫지 않는다.
2. **상시 Independent Judgment Core: 다음 출시에서 자동 주입 제거 결정.** 같은 모델의 Bare가 8쌍에서 동등했고 확인된 고유 효과가 없다. 이는 Core가 해롭다는 증거가 아니라 매번 읽히는 규칙의 필요성이 입증되지 않았다는 뜻이다. 사용자는 이 근거를 들은 뒤 **“다음 출시에서 제거”**를 명시적으로 선택했다. 현재 개발 후보의 manifest·소스나 개인 설치는 이 판정 단계에서 바꾸지 않는다. 다음 출시 준비에서 상시 주입 제거를 구현·검증하고 기존 테스트·설치 경계와 충돌이 없는지 확인한다.
3. **지금 하지 않을 일:** 단일 오분류를 고치려고 전역/프로젝트 보고 규칙을 더 추가하지 않는다. 두 실험 후보를 게임 원본에 병합하거나 개인 패키지를 갱신하지 않는다. 사람 사용성, Core 구성 결정, 출시본 안전 검증·최종 승인은 계속 열어 둔다.

판정 상태: **Phase 4의 증거 검토와 Core 방향 결정 완료, 프로젝트 연결의 최종 사람 가치·출시 승인 미완**. 현재 JOENESS 후보를 READY/정식 출시로 부르지 않는다.
