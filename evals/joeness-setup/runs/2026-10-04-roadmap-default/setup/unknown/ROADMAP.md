# 프로젝트 방향

제품 맥락의 원문: [README.md](README.md).

## 현재

- 현재 단계: 방향 결정 대기. 승인된 목표나 단계는 없다.
- 목표·제품·기술·납기: 미정. 아직 선택하거나 승인하지 않았다.
- 다음 가능한 작업: 사용자가 해결하려는 문제 또는 만들려는 결과 한 가지를 정한다. 선택이 필요하면 후보와 판단 기준을 함께 탐색할 수 있다.
- 의존 경계: 제품 구현과 단계별 계획은 목표 결정이 필요하다. 별도로 승인된 독립 작업은 진행할 수 있다.
- 필수 결과·확인 기준·완료 조건: 목표가 정해지기 전에는 미정이다. 검증할 제품 결과나 완료된 제품 단계는 없다.
- 결정 근거: 최초 설정 요청에서 사용자가 무엇을 만들지 아직 정하지 않았다고 밝혔다.

목표가 승인되면 필요한 만큼만 단계를 정의한다. 각 단계에는 목표, 진입 조건, 서로 독립적으로 확인할 필수 결과, 각 확인 방법과 실제 증거 또는 미검증 범위, 완료 조건, 다음 가능한 작업을 둔다. 방향·범위·순서 변경은 사용자의 명시적 결정으로 기록한다.

실행과 확인 기록: [TASK.md](TASK.md). 개별 작업 완료가 제품 단계나 출시 완료를 뜻하지 않는다.
