# 독서 목록 진행 계획

## 기준과 현재 위치

목표와 승인된 순서의 기준은 [제품 문서](PRODUCT.md)이다. 로컬에서 개인 독서 목록을 관리하며, 계정·클라우드·시각 디자인은 승인 범위에 없다.

- 현재 단계: 1단계 — 책 추가와 제목 검색, 시작 전.
- 다음 가능한 작업: 구현 기술을 결정한다. 기술은 미정이며, 그 선택에 의존하는 구현은 결정 후 진행한다.
- 후속 단계: 2단계 — 저장된 목록 내보내기. 1단계의 실제 앱 검증이 끝날 때까지 대기한다.
- 현재 증거: 제품 문서는 구현이 없다고 명시하며, 연결 시 프로젝트에도 제품 문서 이외의 구현 파일이 없었다. 개별 작업·검증 기록은 [작업 문서](TASK.md)에 둔다.

## 1단계 — 책 추가와 제목 검색

목표: 로컬 앱에서 책을 추가하고 제목으로 검색할 수 있다.

진입 조건: 제품 목표와 순서는 승인되어 있다. 구현 기술은 미정이므로 기술 결정이 그 선택에 의존하는 구현의 선행 조건이다.

- [ ] 책 추가. 상태: 시작 전. 확인: 로컬 앱에서 책을 추가할 수 있는지 실행하여 검증한다. 증거 부족: 구현과 실행 검증이 모두 없다.
- [ ] 제목 검색. 상태: 시작 전. 확인: 로컬 앱에서 추가한 책을 제목으로 검색할 수 있는지 실행하여 검증한다. 증거 부족: 구현과 실행 검증이 모두 없다.

완료 조건: 두 필수 결과가 모두 로컬 앱에서 동작한다는 실제 검증 증거가 있어야 한다. 이는 제품 문서의 내보내기 착수 조건이며, 설정 작업 완료로 충족되지 않는다. 별도 사용자 수락은 확인되지 않았다.

## 2단계 — 저장된 목록 내보내기

목표: 저장된 독서 목록을 내보낼 수 있다.

진입 조건: 1단계의 책 추가와 제목 검색이 로컬 앱에서 동작해야 한다. 내보내기 형식은 미정이며, 1단계 통과 후 형식을 결정한다.

- [ ] 저장된 목록 내보내기. 상태: 시작 전. 확인: 결정된 형식으로 저장 목록을 내보낼 수 있는지 실행하여 검증한다. 증거 부족: 선행 단계 미완료, 형식 미정, 구현·실행 검증 없음. 형식에 따른 구체 확인 방법도 아직 정하지 않았다.

완료 조건: 선행 단계가 충족되고, 결정된 형식으로 내보내기가 동작한다는 실제 검증 증거가 있어야 한다. 형식과 구체 확인 방법을 임의로 확정하지 않는다.

## 진행 갱신

필수 결과는 시작 전·진행 중·검증 대기·보류·완료·범위 제외로 구분한다. 검증 대기와 보류는 미완료다. 검증 결과가 바뀌면 이 문서의 현재 단계와 다음 가능한 작업도 남은 결과에 맞춰 갱신한다. 범위·순서 변경이나 범위 제외에는 명시적 결정과 이유를 남기고 기존 항목을 지우지 않는다. 단계 완료 전에 모든 필수 결과의 실제 증거를 검토한다.
