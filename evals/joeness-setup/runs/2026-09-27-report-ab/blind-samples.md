# 새 담당자 보고 읽기 비교 — A/B

같은 가상 프로젝트, 같은 질문, 같은 모델 설정의 독립 답변입니다. 어느 안내가
어느 답변인지 평가 전에는 공개하지 않습니다. 기계별 절대경로와 커밋 번호만
가렸고, 보이는 주장·순서·검증 수치는 유지했습니다.

처음 보는 사용자 입장에서 한 일, 남은 일, 문제와 다음 행동을 더 빨리
파악할 수 있는 답변을 골라 주세요. A / B / 비슷함 중 하나와 이유 한 줄이면
됩니다.

## A

- 작업: 출하 확정 완료 여부 독립 확인
- 업데이트 파일: 없음
- 이슈: 실제 단말 검증과 결과 기록 누락
- 해결: 미해결 — 로컬 동작 검증은 통과
- 다음 작업: 실제 단말에서 출하 확정·중복 방지 검증 후 결과 기록

상세 보고: **현재 `cases/E`의 M2는 완료라고 할 수 없습니다.** 현재 완료 기준(`cases/E/ROADMAP.md:3`)에 실제 휴대용 단말 검증이 필수로 남아 있습니다.

현재 커밋 `[번호 가림]`의 코드를 확인하고 직접 실행한 결과입니다.

| 확인 항목 | 결과 |
|---|---|
| 출하 번호·경로 보존, 확정 상태 설정, 원본 데이터 유지 | 통과 |
| 기존 번호의 중복 확정 거부 | 통과 |
| `cases/E`에서 `node --test` 실행 | **5개 통과, 실패 0개**, 정상 종료 |
| 동일 요청을 연속 두 번 보내는 별도 확인 | 두 번째 요청 거부, 기존 목록 유지 |
| 실제 휴대용 단말 검증과 결과 기록 | **미확인 — 완료 근거 없음** |

제품 기준(`cases/E/PRODUCT.md:5`)은 이 저장소에 단말이나 에뮬레이터가 없으며, 로컬 테스트로 단말 검증을 대신할 수 없다고 명시합니다. 실제 단말 검증은 이번에도 수행하지 못했고, 저장소에서도 그 결과 기록을 찾지 못했습니다.

과거 자료는 다음처럼 구별해야 합니다.

- `HANDOFF.md`(`cases/E/HANDOFF.md:1`)의 “경로만 고치면 완료”는 오래된 판단입니다. 현재 필수 조건을 충족했다는 근거가 아닙니다.
- `duplicate-probe.md`(`cases/E/evidence/duplicate-probe.md:1`)는 **수정 전** 중복 발생 기록입니다. 현재 코드에는 중복 방지가 있고, 이번 실행에서도 문제는 재현되지 않았습니다.

CSV 내보내기는 명시적으로 제외된 범위(`cases/E/ROADMAP.md:11`)이므로 완료를 막는 항목이 아닙니다. 남은 것은 실제 단말 검증이며, **사용자 최종 수락은 이와 별도이고 아직 기록되어 있지 않습니다.**

코드와 문서는 수정하지 않았으며, 확인 전후 Git 작업 트리에 변경이 없습니다.

## B

**현재 M2는 완료라고 할 수 없습니다.** 배송 확정 기능의 로컬 검증은 통과했지만, 필수 항목인 **실제 휴대 단말 검증(R3)의 실행·결과 기록이 없습니다.**

현재 커밋 `[번호 가림]`에서 코드를 확인하고, `cases/E`의 `node --test`를 직접 실행했습니다. **5개 통과, 0개 실패, 종료 코드 0**입니다.

| 필수 항목 | 독립 확인 결과 |
|---|---|
| R1: ID·경로 보존 | 통과. 확정 상태, 새 목록 반환, 원본 유지도 확인 |
| R2: 중복 ID 차단 | 통과. 기존 배송 상태나 경로가 달라도 중복을 거부하고 원본 유지 |
| R3: 실제 휴대 단말 검증 및 결과 기록 | 미검증. 저장소에 해당 결과가 없으며, 프로젝트 설명에도 단말·에뮬레이터가 제공되지 않는다고 명시 |

이는 현재 완료 기준인 `ROADMAP.md`(`cases/E/ROADMAP.md:3`)와 제품 요구사항(`cases/E/PRODUCT.md:5`)에 따른 판단입니다. CSV 내보내기(O1)는 명시적으로 M2에서 제외됐으므로 완료를 막는 항목이 아닙니다.

오래된 기록은 다음처럼 구분해야 합니다.

- `HANDOFF.md`(`cases/E/HANDOFF.md:1`)의 “경로만 고치면 완료”라는 설명은 이후 요구사항과 작업을 반영하지 않은 옛 인계입니다. 현재 완료 판단에 사용할 수 없습니다.
- `duplicate-probe.md`(`cases/E/evidence/duplicate-probe.md:1`)는 **수정 전 로컬 실행**의 중복 발생 기록입니다. Git 이력에서 당시 원인을 확인했고, 현재 코드에는 차단 처리가 있으며 이번 테스트도 통과했습니다. 이 파일은 현재 결함이나 실제 단말 검증의 증거가 아닙니다.

다음 필요한 작업은 **실제 휴대 단말에서 배송 확정과 중복 거부를 확인하고 결과를 남기는 것**입니다. 사용자 수락은 그와 별개의 결정이며 현재 기록되어 있지 않습니다.

코드와 문서는 수정하지 않았습니다. 확인 전후 Git 작업 트리는 모두 깨끗했습니다.
