전체 관찰:
- 7개 run 모두 네 항목을 다 채웠다(G 4/4). 모두 기존 표에 Result 열을 붙였고, 두 번째 규칙 표를 만든 run은 없다. 모두 CO1~CO3 Check를 DESIGN 규칙 표의 행으로 바꿨다.
- Result 칸은 TASK 링크만 쓴 run이 4개(p3·p6·p7·p8), 결과 수치·상태와 링크를 섞은 run이 3개(p1·p4·p5)다. 로그를 그대로 복사한 run은 없다.
- 렌더를 측정하지 못한 run은 둘로 나뉜다. p3·p6은 CO3를 verification pending으로 두었고, p1은 code 검사만으로 complete로 두면서 미측정을 적었다. 렌더를 측정한 run(p4·p5·p7·p8)은 모두 complete였고, 근거 범위는 행에 적은 범위와 맞았다.
- 렌더를 측정한 run들은 토큰 min-height 44와 렌더 높이 50(padding·border 포함)의 차이를 대체로 밝혔다. 다만 spot check의 check 값을 44로 적은 run과 50으로 적은 run이 있어 표기가 통일되지 않았다.
