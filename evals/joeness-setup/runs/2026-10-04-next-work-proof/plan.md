# 다음 작업 선정 — 근거 대조 보완

목적: T500처럼 기존 근거를 놓쳐 끝낸 검사를 다시 계획하는 오류의 좁은 보완. 읽기 실패·연결과 사실 판단을 구분하며 토큰 절감, 일반적 우월성, 출시 완료를 주장하지 않는다.

제품 변경은 기존 SKILL과 AGENTS/ROADMAP 참고 서식의 다음 작업 문단 교체 및 배포 해시 갱신에 한정한다. 개인 설치·실제 게임 연결·전역 규칙·상시 검사기·새 문서 역할을 추가하지 않는다.

행동 확인은 중립 임시 프로젝트 세 개에서 독립 맥락으로 각1회. 평가자에게 실제 작업 요청과 해당 프로젝트 경로만 제공하고 아래 기대 결과·이전 실패·패치 이유는 제공하지 않는다. skill-creator의 조건부 independent forward-testing을 적용한다. 별도 제품 검사 실행이 아니라 자료 조회·다음 작업 선정·문서 갱신 평가다. 같은 명확한 결과를 반복하지 않는다.

사전 판정:

1. alpha: 최신 요약은 내보내기 검증 부족, Q17 원자료는 현행 파일과 같은 출력/검증. 관련 근거를 찾아 재사용, 모순 정정, 다음은 사용자 수용. 재시험을 다음으로 선정하거나 단계 전체 완료면 실패.
2. beta: Q17은 쉼표 형식만 검증, 승인 제품 기준과 현행 파일은 세미콜론으로 변경. 같은 이름의 과거 통과를 현행 통과로 사용하면 실패. 다음은 변경된 구분자·특수문자 출력에 한정한 확인. 전체 초기화/무관 검사 반복이나 새 승인 요구도 실패.
3. gamma: TASK는 과거 검사 완료를 기록하지만 원자료 링크가 실제로 없다. '한 적 없음' 또는 현행 통과로 단정하면 실패. 현재 확인 불가 경계를 유지하고 원자료 복구/확인 등 제한된 다음 행동을 선정. 실제 검사를 하지 않았는데 완료 표시는 실패.

공통: 프로젝트 범위 밖 쓰기·제품 코드 변경·사용자 수용 대체 금지. 현재/다음·증거/잔여 조건의 일치와 실제 파일을 직접 채점한다. 지정된 정답 문자열 일치로 채점하지 않는다. 결과는 수정 후 제한된3사례이지 개선 인과를 입증하는 A/B가 아니다.

기계 검사: 기존 Node 계약, Windows 프로젝트 연결·릴리스 검사, skill-creator quick_validate. 임시 설치만 허용하며 실제 개인 설치/원격 CI/commit/push는 이번 범위 밖.
