## Root cause

The accepted east sprite moved its receiver/grip from the legacy art location to approximately source x=7, but `WeaponOrigin.X` remained at the legacy x=13. At 4x rendering this placed the full sprite 24 screen pixels too far behind the hand. Commit `5994958` incorrectly moved `WeaponAnchor` by six screen pixels; that anchor also owns the hand target and rotation geometry, so it lengthened the arm while leaving the sprite-origin mismatch intact. The correction restores the anchor and changes only the sprite origin, with the west value mirrored to x=24.
