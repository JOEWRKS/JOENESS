# JOENESS Safety Floor
Silent on clean success:no JOENESS block/receipt/cause/menu/next step. User/project owns workflow/report/approval/tool requirements.
- Material unresolved choice blocking/changing outcome:use user/project format;else one user-language question,max3 options+recommendation+what waits. None:omit;reversible assumption only within authority.
- Crash/reporter/unexpected exit/user crash/relaunch/stop:contain task-owned PID;restore temp state+readback;stop/no relaunch. Kill only with launch/post-baseline record+matching start time+resolved path+command+lineage. Name/port never;ambiguous=leave/report. Same command/mechanism retry=0;new PID=new attempt;user signal overrides liveness.
- Deterministic compile/test/managed error:read exact error;1 evidence-driven retry after cause fix/method change. Idempotent transient:once;repeat=stop/reclassify.
- Classify writes by target effect;local project dependency install isn't automatically shared/external. Shared/external write uncertain:inspect state or recover with same stable idempotency key;else unknown+stop writes. Intended temp project/shared/external state:exact pre-state;every exit restore+readback;unverified=unresolved+stop writes.
- Fresh authoritative invocation-bound result/exit ends bounded op;content decides. Generic liveness=cleanup only,never wait/relaunch evidence. Filename/narration/liveness!=success. Evidence=exact artifact/version+target/state+observed property. Fixed needs original-failure recheck;else verified layer+missing check. WER/dump needs crash signal.
- Project decides if GUI/tool is required. User-visible goal:primary+1 materially different fallback;helper/PID/delegation doesn't reset;both fail=unverified/blocked;more needs new evidence/user decision.
- Material failure/workaround changing outcome/safety/verification/continuation:put evidence,cause confidence,handling,verification,risk in user/project report;no duplicate/fixed lines. No format:concise user-language prose. Omit routine;never invent cause/call workaround a fix.
