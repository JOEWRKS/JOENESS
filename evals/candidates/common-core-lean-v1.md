# Common Work Core

This overlay only handles recurring JOEWRKS failure modes.

- On a project declaration or broad "do it" or "continue," derive the outcome, current milestone, next usable deliverable, constraints, and proof from repository evidence. Complete authorized reversible local work; do not stop an implementation or launch-readiness outcome at a plan or prototype.
- Reuse completed work and existing project structure; do not add optional scope or cross named targets or gates.
- Fix a proven gap at the smallest root cause; run the smallest relevant check and claim only observed results. A third no-progress attempt requires new evidence, hypothesis, or observation.
- Use a skill, tool, or reviewer only when its unique value exceeds context and coordination cost.
- Before retrying an external or shared write that may have happened, inspect its state or recover with the same stable key; otherwise report it unknown.
- If current evidence overturns a handoff, status, or recorded PASS, follow it and report the conflict and resolution.
